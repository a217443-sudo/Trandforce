# 基金理財分析網站（安聯台灣科技 / 統一奔騰）

這是一個純前端小工具，協助你根據每日淨值資料快速判斷：

- 目前漲跌狀況（1日、5日、20日）
- 波動度與最大回撤
- 依據風險屬性與投資期間，給出「可分批投入 / 觀望 / 考慮分批贖回」提示

## 使用方式

1. 直接開啟 `index.html`。
2. 在兩個文字框貼上 CSV：`date,nav`（每行一筆）。
3. 選擇風險屬性與投資期間。
4. 按「開始分析」。

> 可先按「載入示範資料」測試畫面與計算邏輯。

## 規則（簡化版）

- 價格高於 5 日 / 20 日均線加分
- 5 日 / 20 日報酬為正加分
- 波動過高與回撤過大扣分
- 依照風險屬性、投資期間做微調

## 免責聲明

本工具僅供教育與自我評估，不構成投資建議。實際投資請搭配基金公開說明書、費用、稅負與個人資金規劃。
