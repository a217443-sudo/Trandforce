# OKR 追蹤與績效評分管理系統（2026 起）

此專案提供一套可直接落地的資料模型與計算規則，對應您提出的需求：

- 依公司組織（總經理 → 部門 → 課）串聯 OKR。
- 主管登入後可維護每位同仁、不同工作職能、不同年度的 OKR。
- 以 OKR 標準與 1–5 分制進行評分。
- 自 2026 年開始，並支援逐年延續與複製上一年資料。
- 支援年中（Mid-year）與年底（Year-end）達標率統計。

---

## 1. 系統核心設計

### 1.1 組織層級

1. 公司（Company）
2. 事業單位/部門（Department）
3. 課/小組（Team）
4. 員工（Employee）
5. 主管（Manager, 也是 Employee 的角色）

### 1.2 權限角色

- `admin`：系統管理員，可維護組織、人員、職能標準。
- `gm`：總經理層級，可看全公司儀表板。
- `manager`：部門/課主管，只可維護自己管理範圍內同仁。
- `employee`：僅可查看自己的 OKR 與評分結果。

### 1.3 OKR 串聯規則（Alignment）

- 公司年度 Objective（Company O）
  - 對應部門 Objective（Dept O）
    - 對應個人 Objective（Individual O）
      - 每個 Objective 下有 2–5 個 KR（可量化）

每個個人 KR 需紀錄：

- 衡量方式（Metric）
- 起始值（Baseline）
- 目標值（Target）
- 年中實績（Mid Actual）
- 年底實績（Year-end Actual）

---

## 2. OKR 評分標準（1–5 分制）

### 2.1 KR 達成率

達成率公式（數值型 KR）：

`achievement_rate = (actual - baseline) / (target - baseline)`

> 若為「越低越好」指標（如不良率），在 `metric_direction = lower_better` 時使用反向公式，細節見 `schema.sql` 註解。

### 2.2 KR 分數轉換（1–5）

- `< 40%`：1 分
- `40%–59%`：2 分
- `60%–79%`：3 分
- `80%–99%`：4 分
- `>= 100%`：5 分

### 2.3 O（Objective）分數

- Objective 分數 = 該 Objective 底下 KR 加權平均
- 建議 KR 權重總和 = 100%

### 2.4 年度績效總分

建議權重（可調）：

- OKR 達成（70%）
- 職能標準達成（20%）
- 主管行為/協作評估（10%）

年度總分仍換算為 1–5（可保留小數 1 位）。

---

## 3. 年中 / 年底統計指標

### 3.1 年中（6/30）

- 個人年中達標率
- 部門平均達標率
- 風險 KR 清單（達成率 < 60%）

### 3.2 年底（12/31）

- 個人年度達標率
- 部門/全公司達標率
- 依職能別的達標率（例如：製造、採購、工程、行銷）
- 分數分布（1~5 人數占比）

---

## 4. 逐年追蹤與資料帶入

每年建立新一期 `okr_cycle`（例如 2026、2027）：

1. 複製上一年組織與人員關係。
2. 複製上一年未完成但持續性 KR（可選）。
3. 清空 `actual`，保留 baseline/target（由主管調整）。
4. 重新確認該年度職能標準版本。

---

## 6. 快速啟用流程

1. 建立資料庫並執行：
   - `schema.sql`
   - `seed_2026_example.sql`
2. 由主管在 2026 週期建立團隊成員 OKR。
3. 年中輸入 mid actual，跑 `queries.sql` 的年中報表。
4. 年底輸入 year-end actual，產出年度達標與評分。
5. 建立 2027 週期並複製 2026 結構（依第 4 節規則）。
